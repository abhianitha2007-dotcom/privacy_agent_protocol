KEY SAFETY / RESEARCH CONTEXT

Audit records include public cryptographic evidence such as nonces, ciphertext, signatures, fingerprints and observed defense results. Private keys, shared secrets and derived symmetric keys are never recorded. Plaintext is hidden by default; opt-in disclosure is limited to messages from the current process. Section 3 shows only events from the current server run. Previous run metadata is moved to data/previous_sessions/ on restart, and can be reviewed separately. The current run writes to data/security_audit.jsonl.
